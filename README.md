# nishabe.github.io

Personal site of Aneesh Abraham, served by GitHub Pages at https://nishabe.github.io.

Plain static HTML/CSS/JS with no build step and no dependencies.

```
index.html        page content
assets/site.css   styles (light + dark via prefers-color-scheme)
assets/site.js    project dialogs, click-to-load YouTube embeds
img/              favicon and project images
```

Preview locally:

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```
